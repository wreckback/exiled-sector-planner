Build summary

Templates

The game keeps skill tree templates for every save in one file, exiledSector_skillTreeTemplates.json.data, in the saves/common folder of your Starsector install (for example C:\Program Files (x86)\Fractal Softworks\Starsector\saves\common). It re-reads that file whenever the skill tree opens, so changes show up while the game is running.

Templates file

Import

Link the file to see its templates.

Export this build


If the file already has a template with this name and root, it's replaced and keeps its id, so ships using it stay assigned. Otherwise it's added. Other templates are kept as they are.


Share as code

A code holds one template as text, for pasting into chat when sending the file isn't practical. Loading a code works like loading a template from the file; save it into the file afterwards to use it in game.


Other ways to export

Downloads land in your Downloads folder; move the file into saves/common. "Download as a new file" holds only this template, so placing it over an existing file drops the templates already there.
