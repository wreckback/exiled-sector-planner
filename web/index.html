Templates

The game keeps skill tree templates for every save in one file, exiledSector_skillTreeTemplates.json.data, in the saves/common folder of your Starsector install (for example C:\Program Files (x86)\Fractal Softworks\Starsector\saves\common). It re-reads that file whenever the skill tree opens, so changes show up while the game is running.

Import

Link the file to see its templates.

Export this build


If the file already has a template with this name and root, it's replaced and keeps its id, so ships using it stay assigned. Otherwise it's added. Other templates are kept as they are.


Share as code

A code holds one template as text, for pasting into chat when sending the file isn't practical. Loading a code works like loading a template from the file; save it into the file afterwards to use it in game.


Other ways to export

Downloads land in your Downloads folder; move the file into saves/common. "Download as a new file" holds only this template, so placing it over an existing file drops the templates already there.

Story rules

What your campaign has reached. Nodes behind a gate or unlock you untick are refused. Everything starts ticked, so nothing is refused until you change it. Saved with the build and its share link.

Mouse

Left-click a nodeAllocate it, taking the shortest path there
Left-click an allocated nodeRemove it and anything cut off from the root
Left-click an allocated affinity node or socketOpen its picker (switch option, change anchor)
Ctrl+click an affinity or other choice node (Cmd+click on Mac)Allocate it with the option you last picked for that kind of node (choice nodes along the path get it too), or switch an allocated one to it
Shift+click a nodeAdd it as the next waypoint, or drop it if it already is one. The next allocation then goes through the waypoints in order, each leg the shortest legal way from the one before, so you can force a longer route. Esc clears them
Right-click an allocated nodeRemove it (any node type)
Right-click your starting rootAsks first, then resets the build so you can choose a root again (like Reset)
Click a wormhole or linked wormhole exitMenu: jump to the other end, or allocate/remove
Ctrl+click a wormhole, linked socket or linked exit (Cmd+click on Mac)Jump straight to the other end (the view moves; the build doesn't change)
Click a tree's name (when zoomed out)Zoom into that tree
In target mode: left-click a nodeMark it wanted, then forbidden, then clear it (the root can't be marked)
In target mode: right-click a nodeClear its mark
