Templates

The game keeps skill tree templates for every save in one file, exiledSector_skillTreeTemplates.json.data, in the saves/common folder of your Starsector directory. It re-reads that file whenever the skill tree opens, so changes show up while the game is running.

Mouse

Left-click a nodeAllocate it, mapping the shortest path
Left-click an allocated affinity node or socketOpen its picker (switch option, change anchor)
Ctrl+click an affinity or other choice node (Cmd+click on Mac)Allocate all nodes up to that path with the previously chosen option
Shift+click a nodeAdd it as the next waypoint, or drop it if it already is one. The next node allocation then goes through the waypoints in order (the shortest legal path from each waypoint to the next). Can force a longer, specific route. Esc clears waypoints
Alt+click an allocated notable or keystone (Option+click on Mac)Integrate / Remove Integration. Works in summary and list view
Right-click an allocated nodeRemove node
